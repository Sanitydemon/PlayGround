# Soriax: Archmage’s Trial

A complete browser-playable first-person fantasy combat prototype starring Soriax, the immortal kobold Archmage. Built with Three.js; no build step is required. Serve this directory over HTTP (for example, `python3 -m http.server 3002`) and open it in a modern browser with WebGL enabled.

## Controls

- **WASD** move · **Mouse** aim · **Space** jump · **Shift** sprint · **Ctrl** crouch
- **Left mouse** cast · **Right mouse** focus/zoom · **Q / E** cycle equipped spells
- **Tab** cycle target · **F** warding pulse · **R** restore arcane reserve
- **Esc** pause/resume

Choose up to four of seven spells in the pre-encounter loadout. Defeat three escalating waves and an Ancient Colossus boss. Focus/lock the boss’s glowing chest core for bonus damage. Soriax’s immortality restores him at low health rather than ending the run.

The 3D scene, combatants, spell effects, HUD, and Soriax-inspired first-person arms are generated at runtime. Three.js is loaded from jsDelivr, so an internet connection is required to fetch the library.
